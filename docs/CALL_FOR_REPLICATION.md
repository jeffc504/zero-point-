# Call for Independent Replication

If you are a physicist, electrical engineer, materials scientist, vacuum engineer, quantum-device researcher, university laboratory, national laboratory, or serious independent experimenter:

Take the public ideas apart.

Test the simplest hypothesis first. Build controls before building complexity. Measure every input. Publish raw data. Report null results. Identify artifacts. Improve the apparatus where justified.

The project succeeds scientifically even if the answer is “no anomalous energy exists,” provided the experiment resolves the question honestly and reproducibly.

If an anomaly survives calibration, controls, uncertainty analysis, and independent replication, then the evidence—not the marketing—should carry the result.
