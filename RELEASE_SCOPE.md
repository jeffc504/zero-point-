# Release scope

This repository contains only selected sanitized zero-point / quantum-vacuum research documents.

The separate resonant-frequency patent family and every unrelated invention, patent application, software project, private document, and repository are outside this release. This release does not disclose or grant rights to that excluded material.

No raw private archives, personal contact information, credentials, patent claims, proprietary tuning tables, or private implementation files are included.

The public documents are conceptual research descriptions and proposed experiments. They are not a complete hardware build package or evidence of demonstrated net-energy production.

Additional source files must be reviewed individually for this same narrow scope before inclusion. A similar project name does not make a file part of this release.
